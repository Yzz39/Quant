# SMA 均线择时：假突破与滞后止损分析

## 分析的策略

- 数据：`D:/Quant/data/real_etf_daily_eastmoney.csv`
- 标的：数据文件中的 `159915 创业板ETF易方达`、`510300 沪深300ETF华泰柏瑞`、`511010 国债ETF国泰`。
- 参数：SMA `[50, 100, 150, 200, 250]`。
- 入场信号：当日收盘价 `close > SMA(window)`，视为趋势偏强。
- 执行时点：信号 `shift(1)`，也就是下一交易日持仓，避免用当天收盘后才知道的信息在当天成交。
- 出场信号：当日收盘价 `close <= SMA(window)` 后，下一交易日空仓。每次入场/出场扣 `0.10%` 成本。

## 事件定义

- 假突破：入场后持仓不超过 `20` 个交易日，且该笔交易最终亏损。它衡量价格短暂站上均线后很快跌回、被来回打脸的成本。
- 滞后止损：持仓期间浮盈曾达到至少 `8%`，但到出场时较持仓内峰值回吐至少 `8%`。它衡量均线出场慢、把利润还回去的程度。
- 注意：同一笔交易可能同时不是二者，也可能同时满足；这是交易行为诊断，不是独立新策略。
