# 财务数据表详细说明

聚宽平台提供多种财务数据表，涵盖市值、资产负债、现金流、利润、财务指标等。

## 数据表概览

| 表名 | 更新频率 | 统计周期 | 说明 |
|------|----------|----------|------|
| valuation | 每天 | - | 市值数据 |
| balance | 按季度 | 一季度 | 资产负债表 |
| income | 按季度 | 一季度 | 利润表 |
| cash_flow | 按季度 | 一季度 | 现金流量表 |
| indicator | 按季度 | 一季度 | 财务指标 |

## valuation - 市值数据表

**更新频率**: 每天（股本盘前填充，收盘相关指标盘后更新）

### 主要字段

| 字段 | 说明 | 公式 |
|------|------|------|
| capitalization | 总股本(万股) | A股+B股+H股总股本 |
| circulating_cap | 流通股本(万股) | A股流通股本 |
| market_cap | 总市值(亿元) | 收盘价×总股本 |
| circulating_market_cap | 流通市值(亿元) | 收盘价×流通股本 |
| turnover_ratio | 换手率(%) | 成交量/流通股本×100% |
| pe_ratio | 市盈率(TTM) | 总市值/净利润TTM |
| pe_ratio_lyr | 市盈率(PE) | 总市值/去年年度净利润 |
| pb_ratio | 市净率 | 总市值/净资产 |
| ps_ratio | 市销率(TTM) | 总市值/营业收入TTM |
| pcf_ratio | 市现率(TTM) | 总市值/现金净流量TTM |

## indicator - 财务指标

**更新频率**: 按季度，统计周期一季度

| eps | 每股收益(元) | 净利润/期末股本 |

## 使用示例

### 基本面选股

```python
# 低估值高成长选股
q = query(
    valuation.code,
    valuation.pe_ratio,
    valuation.pb_ratio,
    indicator.inc_net_profit_year_on_year,
    indicator.roe
).filter(
    valuation.pe_ratio > 0,
    valuation.pe_ratio < 20,
    valuation.pb_ratio > 0,
    valuation.pb_ratio < 3,
    indicator.inc_net_profit_year_on_year > 20,
    indicator.roe > 15
)

df = get_fundamentals(q, date='2019-12-31')
```

### 财务健康度分析

```python
# 分析公司财务健康度
q = query(
    balance.code,
    balance.total_assets,
    balance.total_liability,
    balance.cash_equivalents,
    cash_flow.net_operate_cash_flow
).filter(balance.code == '000001.XSHE')

df = get_fundamentals(q, statDate='2019q3')

# 计算资产负债率
debt_ratio = df['total_liability'][0] / df['total_assets'][0]
log.info(f"资产负债率: {debt_ratio:.2%}")
```

## 注意事项

1. **数据更新**: 不同表更新频率不同
2. **统计周期**: balance/income/cash_flow/indicator 按季度更新
3. **年度数据**: 使用 statDate 参数查询年度数据
4. **银行业专项**: 银行/券商/保险专项数据只有年报
5. **未来函数**: 使用 statDate 时注意避免未来函数
