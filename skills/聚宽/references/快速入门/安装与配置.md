# 聚宽平台安装与配置

## 平台介绍

聚宽(JoinQuant)是一个专业的量化投资平台,提供完整的策略回测、模拟交易和实盘交易功能。

## 访问平台

聚宽是云端平台,无需本地安装,通过浏览器访问:

- 官网地址: https://www.joinquant.com/
- 研究环境: Jupyter Notebook风格的在线研究环境
- 回测/模拟: 完整的策略回测和模拟交易环境

## 环境配置

### 1. 基础环境

聚宽平台已预装以下Python库:

- pandas
- numpy
- scipy
- matplotlib
- jqdata (聚宽数据接口)
- jqfactor (聚宽因子库)
- jqlib.optimizer (组合优化器)

### 2. 聚宽数据接口

使用聚宽功能前需要导入:

```python
from jqdata import *
```

### 3. 常用配置选项

#### 开启动态复权模式

```python
set_option('use_real_price', True)
```

#### 设置基准

```python
set_benchmark('000300.XSHG')  # 设置沪深300为基准
```

#### 设置交易手续费

```python
set_order_cost(OrderCost(
    close_tax=0.001,           # 印花税
    open_commission=0.0003,    # 买入佣金
    close_commission=0.0003,   # 卖出佣金
    min_commission=5           # 最低佣金
), type='stock')
```

### 4. 策略文件结构

一个完整的聚宽策略包含:

- `initialize(context)` - 初始化函数,只在开始时执行一次
- `handle_data(context, data)` 或定时函数 - 处理交易逻辑

## 策略运行模式

聚宽支持三种运行模式:

1. **回测模式** - 使用历史数据测试策略
2. **模拟交易** - 使用实时数据进行模拟交易
3. **实盘交易** - 连接券商进行真实交易

## 注意事项

- 策略代码运行在安全沙箱环境中
- 支持有限的网络访问(上传10Kbps,下载500Kbps)
- 有严格的超时机制(handle_data超过30分钟将停止)
- 不能写和执行任意文件
- 建议使用`run_daily`等定时函数而非`handle_data`
