# 第一个聚宽策略

一个简单的双均线策略示例，帮助快速上手聚宽平台。

## 完整策略代码

```python
# 导入聚宽函数库
from jqdata import *

# 初始化函数
def initialize(context):
    # 设置基准为沪深300
    set_benchmark('000300.XSHG')

    # 开启动态复权模式
    set_option('use_real_price', True)

    # 设置股票手续费
    set_order_cost(OrderCost(
        open_tax=0,           # 买入时印花税
        close_tax=0.001,      # 卖出时印花税 0.1%
        open_commission=0.0003,   # 买入时佣金 万分之三
        close_commission=0.0003,  # 卖出时佣金 万分之三
        min_commission=5       # 最低佣金 5元
    ), type='stock')

    # 设置要操作的股票
    g.security = '000001.XSHE'  # 平安银行

    # 设置定时任务
    run_daily(before_trading_start, time='before_open')
    run_daily(market_open, time='open')
    run_daily(after_market_close, time='after_close')

# 盘前运行
def before_trading_start(context):
    log.info(f"盘前运行: {context.current_dt}")

# 开盘运行
def market_open(context):
    security = g.security

    # 获取过去20天的收盘价
    hist = attribute_history(security, 20, '1d', ['close'])

    # 计算均线
    MA5 = hist['close'][:5].mean()   # 5日均线
    MA20 = hist['close'].mean()      # 20日均线

    # 获取当前价格
    current_price = hist['close'][-1]

    # 获取当前资金
    cash = context.portfolio.available_cash

    # 获取当前持仓
    position = context.portfolio.positions[security]
    closeable_amount = position.closeable_amount

    # 交易逻辑：金叉买入，死叉卖出
    if MA5 > MA20:  # 金叉
        if cash > current_price * 100:  # 有足够资金
            # 买入
            order_value(security, cash)
            log.info(f"买入 {security}, 价格: {current_price}, 均线 MA5: {MA5}, MA20: {MA20}")
    elif MA5 < MA20:  # 死叉
        if closeable_amount > 0:  # 有持仓
            # 卖出
            order_target(security, 0)
            log.info(f"卖出 {security}, 价格: {current_price}, 均线 MA5: {MA5}, MA20: {MA20}")

    # 记录数据用于绘图
    record(price=current_price, MA5=MA5, MA20=MA20)

# 收盘后运行
def after_market_close(context):
    log.info(f"盘后运行: {context.current_dt}")

    # 统计当天交易
    orders = get_orders()
    for order in orders.values():
        log.info(f"订单: {order.security}, 数量: {order.amount}, 状态: {order.status}")

    # 查看持仓
    log.info(f"总资产: {context.portfolio.total_value}")
    log.info(f"持仓市值: {context.portfolio.positions_value}")
    log.info(f"可用资金: {context.portfolio.available_cash}")
```

## 策略说明

### 策略思路

1. **技术指标**: 使用5日均线和20日均线
2. **买入信号**: 当5日均线上穿20日均线（金叉）时买入
3. **卖出信号**: 当5日均线下穿20日均线（死叉）时卖出
4. **仓位管理**: 满仓买入，空仓卖出

### 函数说明

| 函数 | 说明 | 调用频率 |
|------|------|----------|
| initialize | 初始化，只运行一次 | 策略开始 |
| before_trading_start | 盘前准备 | 每天 |
| market_open | 交易逻辑 | 每天 |
| after_market_close | 盘后统计 | 每天 |

### 运行流程

```
策略开始
  ↓
initialize() ← 只运行一次
  ↓
每个交易日:
  before_trading_start() ← 开盘前
  ↓
  market_open() ← 开盘
  ↓
  after_market_close() ← 收盘后
  ↓
策略结束
```

## 常见问题

### Q: 为什么没有交易？

A: 检查以下几点：
- 是否有足够的资金
- 均线条件是否满足
- 股票是否停牌
- 交易时间是否正确

### Q: 手续费太高？

A: 调整手续费设置或减少交易频率。

### Q: 如何查看详细日志？

A: 点击回测结果页面的"日志"标签。
