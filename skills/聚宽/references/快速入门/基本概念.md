# 聚宽基本概念

## 标的代码格式

聚宽平台使用标准化的标的代码格式：

### 股票代码

```
股票代码.交易所后缀
```

- **深交所股票**: 000001.XSHE
- **上交所股票**: 600000.XSHG

### 指数代码

- **沪深300**: 000300.XSHG
- **上证50**: 000016.XSHG
- **中证500**: 000905.XSHG
- **中证1000**: 000852.XSHG

### 期货代码

```
合约代码.交易所后缀
```

- **股指期货** (CCFX): IF2401.CCFX, IH2401.CCFX, IC2401.CCFX
- **国债期货** (CCFX): T2403.CCFX, TF2403.CCFX
- **商品期货** (XSGE): AU2406.XSGE, CU2403.XSGE
- **商品期货** (XDCE): RB2405.XDCE, AG2406.XDCE

### 基金代码

- **ETF**: 510300.XSHG, 159902.XSHE

## 策略生命周期

### 1. 初始化阶段 (initialize)

整个策略运行期间只执行一次。

```python
def initialize(context):
    # 设置基准、手续费、股票池
    # 设置定时任务
    # 初始化全局变量
```

### 2. 盘前阶段 (before_trading_start)

每个交易日开盘前执行一次。

```python
def before_trading_start(context):
    # 获取最新数据
    # 选股
    # 计算买入卖出列表
```

### 3. 交易阶段 (handle_data / market_open)

每个 bar 执行一次（天/分钟）。

```python
def handle_data(context, data):
    # 交易逻辑
    # 下单
```

### 4. 盘后阶段 (after_trading_end)

每个交易日收盘后执行一次。

```python
def after_trading_end(context):
    # 统计分析
    # 记录日志
```

## 核心对象

### g - 全局变量对象

用于存储全局数据，支持序列化。

```python
g.security = '000001.XSHE'
g.count = 0
```

### context - 策略上下文

包含账户、时间等信息。

```python
context.current_dt        # 当前时间
context.portfolio         # 账户信息
context.previous_date     # 前一交易日
```

### data - 当前数据

包含当前 bar 的行情数据。

```python
data['000001.XSHE'].close  # 收盘价
data['000001.XSHE'].volume # 成交量
```

## 复权方式

- **pre**: 前复权（默认）
- **post**: 后复权
- **none**: 不复权

前复权价格 = 原始价格 / 复权因子

## 时间概念

| 概念 | 说明 |
|------|------|
| context.current_dt | 当前 bar 的开始时间 |
| context.previous_date | 前一个交易日 |
| datetime | datetime.datetime 对象 |
| date | datetime.date 对象 |

## 注意事项

1. **未来函数风险**: 不能使用未来数据
2. **停牌处理**: 停牌股票有数据但不能交易
3. **涨跌停限制**: 涨跌停时可能无法成交
4. **T+1 制度**: 当天买入的股票不能当天卖出
5. **手续费**: 交易需要考虑手续费和滑点
