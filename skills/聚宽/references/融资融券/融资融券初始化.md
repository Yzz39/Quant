# 融资融券初始化

启用融资融券功能,允许进行融资买入和融券卖出。

## 函数签名

```python
enable_margin()
```

## 参数

无参数

## 返回值

无返回值

## 示例

```python
def initialize(context):
    # 启用融资融券
    enable_margin()
```

## 融资融券说明

### 融资买入

- 借资金买入证券
- 需要支付利息
- 需要提供保证金

### 融券卖出

- 借证券卖出
- 需要支付利息
- 需要提供保证金
- 未来需要买回还券

## 账户结构

启用融资融券后,账户包含:
- 普通账户: 现金和自有证券
- 信用账户: 融资融券的持仓和资金

## 注意事项

1. 必须在initialize中调用
2. 融资融券有额外成本
3. 有维持保证金要求
4. 可能面临强制平仓风险
