# 期货保证金设置

设置期货交易的保证金比例。

## 函数签名

```python
set_order_cost(cost, type='future')
```

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| cost | OrderCost | 保证金设置对象 |
| type | str | 类型,设为'future' |

## OrderCost 参数

```python
OrderCost(
    open_tax=0,           # 开仓税率
    close_tax=0,          # 平仓税率
    open_commission=0,     # 开仓佣金
    close_commission=0,    # 平仓佣金
    min_commission=0       # 最低佣金
)
```

## 示例

```python
def initialize(context):
    # 设置期货保证金和手续费
    set_order_cost(
        OrderCost(
            open_tax=0,           # 期货无印花税
            close_tax=0,
            open_commission=0.0001,   # 开仓手续费万分之一
            close_commission=0.0002,  # 平仓手续费万分之二
            min_commission=10
        ),
        type='future'
    )
```

## 期货保证金说明

1. 聚宽默认按交易所标准设置保证金
2. 可以自定义保证金比例
3. 手续费通常是按成交金额的一定比例
4. 不同品种的手续费不同

## 注意事项

1. 期货交易需要设置保证金
2. 注意杠杆风险
3. 手续费双向收取
