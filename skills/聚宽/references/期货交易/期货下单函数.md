# 期货下单函数

聚宽提供专门的期货下单函数,支持开仓、平仓、多空交易。

## 函数列表

### 1. order - 期货下单

```python
order(security, amount)
```

- amount > 0: 开多仓或平空仓
- amount < 0: 开空仓或平多仓

### 2. 开仓函数

```python
# 开多仓
open_long(security, amount)

# 开空仓
open_short(security, amount)
```

### 3. 平仓函数

```python
# 平多仓
close_long(security, amount)

# 平空仓
close_short(security, amount)
```

## 示例

```python
# 开多仓
order('IF2401.CCFX', 1)
# 或
open_long('IF2401.CCFX', 1)

# 开空仓
order('IF2401.CCFX', -1)
# 或
open_short('IF2401.CCFX', 1)

# 平多仓
close_long('IF2401.CCFX', 1)

# 平空仓
close_short('IF2401.CCFX', 1)
```

## 期货特有概念

1. **开多**: 买入开仓,看涨
2. **开空**: 卖出开仓,看跌
3. **平多**: 卷出平仓,平掉多单
4. **平空**: 买入平仓,平掉空单
5. **双开**: 双方同时开仓
6. **双平**: 双方同时平仓
7. **换手**: 旧平新开

## 注意事项

1. 期货交易使用保证金制度
2. 先开仓后平仓
3. 注意持仓方向和数量
4. 到期月份需要换月
