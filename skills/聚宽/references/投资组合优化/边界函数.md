# 边界函数

设置单个证券的权重范围。

## Bound - 权重边界

```python
from jqlib.optimizer import Bound

# 设置权重边界
bound = Bound(low=0.0, high=0.1)
```

## 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| low | float | 权重下限 |
| high | float | 权重上限 |

## 使用示例

### 单一边界

```python
# 所有股票权重不超过10%
bounds = [Bound(0, 0.1)]

optimized_weight = portfolio_optimizer(
    date=context.previous_date,
    securities=g.stock_pool,
    target=MaxSharpeRatio(rf=0.03, count=250),
    bounds=[Bound(0, 0.1)]
)
```

### 多个边界

```python
# 为不同证券设置不同边界
bounds = [
    Bound(0, 0.2),  # 第一只股票不超过20%
    Bound(0, 0.1),  # 第二只股票不超过10%
    # ...
]
```

### 零售边界

允许某些证券不持有:

```python
# 权重可以为0,表示可以不持有
bound = Bound(0, 0.1)
```

## 注意事项

1. 边界为列表,与证券列表一一对应
2. 单一边界应用于所有证券
3. low=0表示允许不持有
4. 边界设置合理才能有解
