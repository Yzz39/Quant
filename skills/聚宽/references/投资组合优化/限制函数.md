# 限制函数

投资组合优化的约束条件。

## 支持的约束函数

### 1. WeightConstraint - 权重约束

限制组合总权重范围。

```python
from jqlib.optimizer import WeightConstraint

# 组合权重在90%到100%之间
constraint = WeightConstraint(low=0.9, high=1.0)
```

### 2. MarketConstraint - 市值约束

按市场类型限制权重。

```python
from jqlib.optimizer import MarketConstraint

# 股票总权重0-90%
MarketConstraint('stock', low=0.0, high=0.9)

# ETF总权重0-10%
MarketConstraint('etf', low=0.0, high=0.1)
```

### 3. AnnualProfitConstraint - 年化收益约束

限制组合年化收益率下限。

```python
from jqlib.optimizer import AnnualProfitConstraint

# 年化收益率不低于10%
constraint = AnnualProfitConstraint(limit=0.1, count=250)
```

### 4. MaxDrawdownConstraint - 最大回撤约束

限制组合最大回撤。

```python
from jqlib.optimizer import MaxDrawdownConstraint

# 最大回撤不超过20%
constraint = MaxDrawdownConstraint(limit=0.2, count=250)
```

## 使用示例

```python
optimized_weight = portfolio_optimizer(
    date=context.previous_date,
    securities=g.stock_pool,
    target=MaxSharpeRatio(rf=0.03, count=250),
    constraints=[
        WeightConstraint(low=0.9, high=1.0),
        MarketConstraint('stock', low=0.0, high=0.9),
        MarketConstraint('etf', low=0.0, high=0.1),
        AnnualProfitConstraint(limit=0.1, count=250)
    ],
    bounds=[Bound(0, 0.1)]
)
```

## 注意事项

1. 可以添加多个约束条件
2. 约束过多可能导致无解
3. count参数建议使用250
4. 返回None表示优化失败
