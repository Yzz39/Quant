# 优化目标函数

投资组合优化的目标函数。

## 支持的目标函数

### 1. MinVariance - 最小方差

最小化组合风险。

```python
from jqlib.optimizer import *

target = MinVariance(count=250)
```

### 2. MaxProfit - 最大收益

最大化组合收益。

```python
target = MaxProfit(count=250)
```

### 3. MaxSharpeRatio - 最大夏普比率

最大化风险调整后收益。

```python
target = MaxSharpeRatio(rf=0.0, weight_sum_equal=0.5, count=250)
```

参数:
- rf: 无风险利率
- weight_sum_equal: 权重和约束
- count: 历史数据天数

### 4. MinTrackingError - 最小追踪误差

最小化与基准的跟踪误差。

```python
target = MinTrackingError(benchmark='000300.XSHG', count=250)
```

### 5. RiskParity - 风险平价

等风险贡献配置。

```python
target = RiskParity(count=250, risk_budget=None)
```

### 6. MaxFactorValue - 最大化因子值

最大化组合的因子暴露。

```python
target = MaxFactorValue(factor=factor, count=1)
```

### 7. 自定义目标

可以自定义目标函数。

## 使用示例

```python
optimized_weight = portfolio_optimizer(
    date=context.previous_date,
    securities=g.stock_pool,
    target=MaxSharpeRatio(rf=0.03, count=250),
    constraints=[],
    bounds=[Bound(0, 0.1)]
)
```

## 注意事项

1. count参数建议使用250个交易日(约一年)
2. 不同目标函数适合不同场景
3. 夏普比率最大化需要指定无风险利率
4. 风险平价适合长期配置
