# 04O：M3去除21日确认重跑计划

## 状态

- 当前版本：v0.3-m3b-result
- 当前状态：M3A与M3B-v0.13均已完成且失败；M3B属于用户越过M3A关卡后的探索性补充
- 引擎版本：v0.13
- 首个模式：`RUN_MODE = "m3_ols_slope"`
- 选择策略：`M3_SELECTION_POLICY = "ranked_factor_only"`
- 本版本是独立策略规则变化，不覆盖旧逻辑或v0.12结果

## 一、研究问题

v0.12要求非货币候选同时满足“长期因子分数大于0、最近21日收益大于0”。七个模式均未通过，且多个斜率分支的低排名候选全部失败。本版本单独检验：完全取消M3的21日正动量门槛，只保留各因子自己的长期方向和排名，能否避免21日反转噪声造成的过早防守。

该问题只适用于M3A至M3G。M2继续检查Top1的126日和21日收益，M2R继续逐名检查126日和21日收益，二者不随v0.13改变。

## 二、统一选择流程

M3A至M3G使用以下流程：

```text
按各自长期因子分数降序排名
-> 从第一名开始逐名检查
-> 遇到货币ETF：直接持有货币ETF并停止
-> 非货币ETF因子分数>0：选择并停止
-> 非货币ETF因子分数<=0：记录到excluded并继续下一名
-> 没有候选通过且货币ETF不可用：空仓
```

`recent_score`和`recent_pass`继续写入日志和成熟标签，只作诊断，不参与目标选择。非货币候选即使`recent_pass=False`，只要长期因子分数大于0，也必须出现`decision=ranked_factor_pass`并被选中。

## 三、逐名检查的数学边界

候选已经按同一个因子分数降序排列。因此在全部分数有限、可交易池已经过滤完成的前提下：

```text
若排名第一的非货币候选score<=0
则所有排名更低的非货币候选score也<=0
```

所以取消21日门槛后，不可能因为第一名因子分数失败而改选第二名风险资产。逐名检查仍然保留，以明确处理货币ETF在排名中的位置、负分候选和货币ETF不可用的边界；正常情况下，风险资产只会以`selected_rank=1`被选择，`selected_rank>1`主要对应跳过非正分风险资产后到达货币ETF。

本版本实质上是“各M3因子的正向Top1 + 排名位置上的货币ETF防守”基线。若回测出现`selected_rank>1`且选择非货币ETF，应首先按实现错误审计，而不能解释为策略发现了低排名机会。

## 四、保持不变

- 四资产核心池和点时可交易性检查；
- 各M3因子公式及参数；
- 127点长期价格窗口和月末信号；
- 21日数据的计算与日志记录；
- 100,000元本金、分钟回测和下一交易日执行；
- 佣金、滑点、最低费用、整手、流动性限制和跨日重试；
- 21日未来趋势标签定义；
- M3F的中心化Borda融合公式。

M3F的Borda分数大于0只代表综合排名高于截面平均，不等于资产自身长期收益为正。v0.13继续保留原`score>0`解释，不借本次实验调整融合权重或分数定义。

## 六、对照与归因

每个模式至少与v0.12同模式比较：

- `recent_pass=False`但因子正分时由防守改为持有风险资产的月份；
- 风险资产暴露月份、货币ETF月份和换仓次数；
- 按“最近21日正/负”拆分的未来21日标签精确率和平均净收益；
- 累计收益、年化、最大回撤、Calmar、Sharpe、Sortino和成本；
- 最差月份、最差持有期及回撤是否集中于取消确认后的负近期动量样本；
- 相对旧逻辑和v0.12的收益增量是否依赖单一ETF、年份或交易；
- M3A与M3D、M3B与M3G是否仍产生相同目标序列。

v0.12的完整结果和标签口径见[`04N_M3排名内继续确认重跑计划.md`](04N_M3排名内继续确认重跑计划.md)。

## 七、标签口径

现有`S04_LABEL_SUMMARY`会把货币ETF目标计入`selected=1`。正式验收必须另外排除`511880.XSHG`，只统计风险资产趋势确认；货币ETF只记录为防守次数。原始汇总保留用于日志完整性复核，但不得直接作为55%精确率结论。

本版本还必须把风险资产标签按信号日的`recent_pass`分组：

- `recent_pass=True`：原v0.12本来也允许选择的样本；
- `recent_pass=False`：本版本新增的风险暴露，是检验“取消21日确认”是否有效的核心样本。

只有后一组提供稳定正增量，才能说明移除21日门槛有价值。

## 八、通过条件

首先满足步骤04绝对门槛：风险资产成熟选择不少于36、精确率不低于55%且高于21.58%无条件成功率至少5个百分点、平均21日净收益为正、年化不低于6.22%、最大回撤不高于34.96%、Calmar不低于0.4、至少60%完整年度为正，并且执行无异常。

随后满足相对v0.12的增量条件：精确率提高至少5个百分点或Calmar提高至少0.05；年化下降不超过1个百分点；最大回撤恶化不超过2个百分点；改善不集中于单一ETF、年份、近期动量分组或交易。

即使组合收益提高，如果`recent_pass=False`新增样本的精确率和平均净收益没有改善，也不能把结果解释为趋势确认优化。
