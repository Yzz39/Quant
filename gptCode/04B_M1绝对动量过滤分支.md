## 一、分支目的

M0的结果显示，126日相对Top1虽然有一定信息增益，但满仓持有导致最大回撤43.70%，Calmar约0.178。M1只检验一个新增假设：

> 相对最强资产只有在自身126日收益为正时才值得持有；否则转入货币ETF。

这不是对M0参数的事后优化，而是依据步骤00预先登记的“相对动量与绝对动量分离”机制建立的新分支。M0结果永久保留，不能用M1结果覆盖M0失败。

## 二、唯一变更

除以下规则外，M1与M0完全相同：

| 项目 | M1规则 |
|---|---|
| 相对排名 | 仍按过去126个交易日收益率选择Top1 |
| 绝对过滤 | Top1自身126日收益`> 0`才允许持有 |
| 过滤失败 | 目标切换为`511880.XSHG`货币ETF，目标权重100% |
| 货币ETF不可用 | 目标为空仓，保留现金并记录`cash_unavailable` |
| 其他 | 池子、月频、T+1执行、费用、滑点、容量和日志合同全部不变 |

注意：Top1仍然记录在信号中，但当绝对过滤失败时，该月份不把Top1计为“实际确认信号”；趋势标签只统计真正被持有的Top1月份。

## 三、聚宽运行设置

使用`step04_joinquant_momentum_baseline.py`，只修改：

```python
RUN_MODE = "m1_absolute"
```

其他设置保持：

- 分钟频率
- 2015-01-01至2020-12-31
- 初始资金100,000元
- `use_real_price=True`
- `avoid_future_data=True`
- 货币ETF：`511880.XSHG`

必须保留`S04_SIGNAL`中的`selected`、`absolute_pass`、`decision`和`target`字段。重点检查：

- `decision=cash_filter`时目标确实为`511880.XSHG`；
- 没有负现金、`violation=1`、`S04_BLOCK`或`S04_EXPIRE`；
- 货币ETF切换也遵守先卖后买和T+1规则；
- 每个趋势标签只成熟一次。

## 四、M1通过条件

M1必须与M0共同可用区间比较，并满足：

- [ ] Top1实际确认精确率不低于55%，且至少高于同期无条件成功率5个百分点；
- [ ] 实际确认信号的未来21日平均净收益为正；
- [ ] Calmar不低于0.4；
- [ ] 最大回撤相对M0至少下降20%，或年化收益不低于M0的80%且回撤明显下降；
- [ ] 至少60%的完整自然年度收益为正；
- [ ] 不依赖单个ETF、单一年份或日志截断前的局部区间；
- [ ] 2倍成本和延迟1个交易日后，风险改善仍然存在。

若M1仍未通过，停止继续叠加M2多周期一致性、TopN或止损；需要重新评估大类资产相对动量假设。

实际结果表明M1并非“有效规则回测后失败”，而是因为货币ETF已在排名池中导致条件近乎恒成立，交易路径与M0相同。经用户明确要求继续优化后，M2作为独立新假设建立，不在M1上叠加参数；TopN、止损和步骤05仍保持阻塞。
