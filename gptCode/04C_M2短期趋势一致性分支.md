## 状态

## 一、研究假设

M0使用126日累计收益选强者，但2015年大回撤表明长期分数可能在趋势反转后仍保持高位。M1检查同一个126日分数是否大于0，由于货币ETF已经在排名池中且通常为正，规则近乎恒成立。

M2只新增一个独立信息：

> 126日相对强度负责选择资产，最近21个交易日收益负责确认趋势尚未转弱。

21个交易日对应约一个月，与月度调仓和未来21日趋势标签一致。本分支不扫描其他短周期。

## 二、冻结规则

| 项目 | M2规则 |
|---|---|
| 长周期选择 | 四袖套按126日收益率排名，选择Top1 |
| 短周期确认 | 非货币Top1最近21日收益必须`> 0` |
| 确认通过 | 目标为Top1，权重100% |
| 确认失败 | 目标为`511880.XSHG`，权重100% |
| 货币ETF为Top1 | 直接持有货币ETF，不再要求其21日收益为正 |
| 货币ETF不可用 | 空仓持有现金并记录`cash_unavailable` |
| 其他条件 | 池子、126日排名、月频、T+1执行、成本、滑点、容量和本金均与M0相同 |

唯一新增信号是非货币Top1的21日收益方向。不得同时加入TopN、均线、止损、波动率或其他周期。

## 三、聚宽运行

使用`step04_joinquant_momentum_baseline.py`。脚本当前默认：

```python
RUN_MODE = "m2_recent_confirm"
RECENT_LOOKBACK = 21
```

运行设置保持分钟频率、2015-01-01至2020-12-31、初始资金100,000元。

关键日志：

- `S04_CONFIG`必须显示`mode=m2_recent_confirm`和`recent_lookback=21`；
- `S04_SIGNAL`必须记录`recent_score`、`recent_pass`和`decision`；
- `decision=recent_filter`时目标必须为`511880.XSHG`；
- 不得出现负现金、`violation=1`、意外重复标签或未来数据警告。

## 四、通过条件

M2必须同时满足：

- [ ] 实际Top1确认标签不少于36个；
- [ ] 实际Top1趋势精确率不低于55%，且至少高于同期无条件成功率5个百分点；
- [ ] 实际确认信号未来21日平均净收益为正；
- [ ] Calmar不低于0.4；
- [ ] 最大回撤相对M0的43.70%至少下降20%，即不高于34.96%；
- [ ] 年化收益不低于M0的80%，即不低于6.22%；
- [ ] 至少60%的完整自然年度收益为正；
- [ ] 结果不依赖单个ETF或单一年份。

任一核心条件失败，M2停止，不继续叠加M3或进入步骤05。

## 五、首次运行审计

首次运行的方向性结果为年化9.62%、最大回撤21.16%、Calmar约0.455，但不得计入正式结论，原因如下：

1. 聚宽初始资金为200,000元，与冻结的100,000元不一致；
2. 回测频率为每天，与冻结的分钟频率不一致；
3. 2016-01-04部分买入717/2200份后被错误判定执行完成；
4. 2018-09-04部分卖出后剩余22份`511010.XSHG`，零碎仓位未清理，信号随后过期；
5. 2019-05-06不足100份的补仓委托被拒绝，代码仍记录执行完成。

该运行中成熟的实际选择标签为38个，成功10个，表面精确率约26.3%，也未达到55%门槛。由于仓位路径已经被执行错误改变，组合收益、回撤和标签统计只作排错证据。

修复步骤03后，M0和M2都必须使用100,000元、分钟频率、2015-01-01至2020-12-31重新运行。M2信号参数不得因本次结果修改。
