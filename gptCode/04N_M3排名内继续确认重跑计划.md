# 04N：M3排名内继续确认重跑计划

## 状态

- 当前版本：v0.2-results
- 当前状态：M3A至M3G已全部完成聚宽重跑和日志审计；没有模式通过采用门槛
- 引擎版本：v0.12
- 已运行模式：`m3_ols_slope`至`m3g_efficiency_rank`
- 本版本是策略规则变化，不覆盖M3A至M3G旧结果

## 一、研究问题

旧M3逻辑先按因子选第一名；第一名因子分数或最近21日收益不为正时，直接持有货币ETF。新版本检验：第一名失败后继续检查排名靠后的候选，能否保留仍处于有效趋势的第二名或第三名。

## 二、统一选择流程

对M3A至M3G全部使用：

```text
按各自长期因子分数降序排名
-> 逐名检查
-> 遇到货币ETF：直接持有货币ETF并停止
-> 非货币ETF同时满足“因子分数>0、最近21日收益>0”：选择并停止
-> 否则记录到excluded并继续下一名
-> 没有候选通过且货币ETF不可用：空仓
```

本版本只改变“第一名失败后的处理”。因子公式、127点窗口、21日窗口、候选池、月频、Top1、成本、滑点、T+1、整手和重试规则全部不变。

## 三、模式顺序

1. `m3_ols_slope`；
2. `m3b_efficiency`；
3. `m3c_bias_trend`；
4. `m3d_wls_slope`；
5. `m3e_huber_slope`；
6. `m3f_equal_rank`；
7. `m3g_efficiency_rank`。

M3B与M3G因子公式相同，但用户要求全部模式应用统一逻辑，因此均保留运行入口；研究结论中不得把二者视为两份独立因子证据。

## 四、解释边界

- OLS、WLS、Huber、效率和乖离分数的正负具有方向含义；
- M3F的Borda融合分数大于0仅表示综合排名高于截面平均，不等于资产自身长期收益为正；本重跑保留旧M3F已有的`score>0`条件，只改变失败后是否继续检查；
- 该实验族是在看到M2R历史改善后建立，属于事后授权的探索性版本，不能与原预注册M3结果混称；
- 如果多个模式改善，必须检查增益是否全部来自相同的排名内继续机制，而不是各自因子。

## 五、每个模式必须对照

每个v0.12模式与自己的旧版本比较：

- 第一名失败次数；
- 选择第2、3、4名以及货币ETF的次数；
- 与旧版本选择不同的月份；
- 不同`selected_rank`的收益贡献和趋势成功率；
- 成熟选择数、精确率、无条件成功率和平均21日净收益；
- 年化、最大回撤、Calmar、Sharpe、Sortino、换手和成本；
- 是否出现负现金、重复订单、部分成交错误或持仓偏差。

## 六、通过条件

首先满足步骤04绝对门槛：成熟选择不少于36、精确率不低于55%且高于无条件成功率至少5个百分点、平均21日净收益为正、年化不低于6.22%、最大回撤不高于34.96%、Calmar不低于0.4、至少60%完整年度为正，并且执行无异常。

随后满足相对旧版本的增量条件：精确率提高至少5个百分点或Calmar提高至少0.05；年化下降不超过1个百分点；最大回撤恶化不超过2个百分点；改善不集中于单一ETF、年份、排名或交易。

## 八、统计口径修正

v0.12日志把货币ETF目标也记为`selected=1`，导致最终`S04_LABEL_SUMMARY`把防守仓纳入“趋势确认”精确率。货币ETF在排名中一旦被遇到便无条件持有，并不要求自身通过`score>0`和21日确认；同时统一成功标签要求未来21日净收益不低于1%，该门槛不适合评价货币ETF。

因此本次同时保留两套口径：

- 原始日志汇总用于复核日志完整性；
- 验收趋势确认能力时排除`511880.XSHG`，只统计实际选择的风险资产；
- 货币ETF次数单独作为防守仓记录，不计为趋势确认成功或失败；
- 该修正只改变研究统计解释，不改变任何历史订单、持仓或收益曲线。

所有模式共有278个成熟资产标签、60个成功标签，无条件成功率为21.58%。
