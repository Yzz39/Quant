## 本步骤目标

说明ETF动量策略可能获得收益的经济与行为机制，并把每个机制转换为后续可独立验证的策略模块。后续优化只能来自本步骤预先登记的假设，不能在看到回测结果后为任意指标补写理论故事。

本项目研究的核心不是“过去涨的ETF必然继续涨”，而是检验以下命题：

> 不同大类资产及ETF组合对信息和宏观冲击的价格调整可能不是瞬时完成的，中期相对强弱和自身趋势可能包含有限的延续信息；若这种信息在扣除交易成本、控制风险和避免未来数据后仍然存在，才可能形成可交易的ETF轮动策略。

这是待检验假设，不是已经成立的事实。

## 一、两类动量

### 1.1 相对动量

相对动量也称横截面动量：在同一时点比较多个资产的过去收益或趋势强度，持有其中相对较强的资产。

```text
权益、国债、黄金、现金 -> 比较相对强弱 -> 选择排名靠前的袖套
```

它回答“现在谁更强”，但不能判断排名第一的资产本身是否处于下跌趋势。如果所有风险资产都在下跌，相对最强者仍可能产生负收益。

### 1.2 绝对动量

绝对动量也称时间序列动量：将某个资产当前趋势与自身历史、零收益或现金收益比较，判断其是否值得持有。

```text
某资产相对最强 + 自身趋势为正 -> 可以持有
某资产相对最强 + 自身趋势为负 -> 转入防守或现金候选
```

相对动量主要用于资产选择，绝对动量主要用于风险过滤。两者必须分别验证，不能在第一个基线版本中同时加入后把全部效果统称为“动量”。

## 二、动量可能存在的一般机制

### 2.1 信息扩散和反应不足

新信息通常由不同投资者在不同时间理解和交易。部分投资者受研究能力、交易限制、确认偏误或调整成本影响，不会立即完成仓位变化，价格可能分阶段向新均衡移动。

可检验含义：中期收益可能存在延续，但极短期噪声和长期估值修复未必具有同样方向。

### 2.2 羊群、注意力和反馈交易

上涨会提高媒体关注、基金申购和投资者参与度，新增资金又可能推动趋势继续；下跌则可能触发赎回和风险预算收缩。

可检验含义：趋势可能延续，也可能在拥挤后发生急剧反转。因此动量收益不能脱离尾部回撤和反转风险报告。

### 2.3 宏观状态具有持续性

经济增长、通胀、利率、信用和流动性通常不会每天随机切换。不同大类资产对这些状态的敏感度不同，宏观状态的持续性可能表现为资产收益趋势。

可检验含义：大类资产中低频动量可能比高频交易更符合经济机制，但不能使用事后确认的宏观阶段标签生成信号。

### 2.4 机构资金调整不是瞬时完成

公募基金、保险、养老金和其他机构受基准、申赎、风险预算、合规和流动性约束，大规模调仓往往分批完成。

可检验含义：资产和行业相对强弱可能持续一段时间，但成交拥挤和容量约束必须计入成本。

### 2.5 风险补偿解释

动量收益也可能不是市场错误，而是承担了趋势反转、流动性枯竭或危机期相关性上升等风险的补偿。

可检验含义：高收益若集中来自少数时期，或伴随无法接受的动量崩溃，不能仅凭年化收益认定策略有效。

## 三、A股市场中的可能作用机制

以下内容只说明为什么A股值得检验动量，不表示这些机制一定增强收益。

### 3.1 投资者结构和注意力差异

A股参与者的信息处理能力、持有周期和交易目标差异较大，热点、政策和主题信息可能分阶段扩散。该特征可能产生趋势延续，也可能产生更强的追涨杀跌和短期反转。

### 3.2 涨跌停、T+1和卖空约束

涨跌停、股票T+1和卖空限制可能延迟底层股票的价格发现，使冲击跨多个交易日反映；同时也可能积累隔夜跳空和连续跌停风险。ETF本身及底层成分的交易约束必须分别考虑。

### 3.3 政策和产业周期

产业政策、信用周期、财政支出和监管变化常对一组公司或资产产生持续影响，可能形成宽基、行业或风格层面的阶段性趋势。但政策标签通常难以实时、客观地量化，首轮策略只使用价格和成交数据验证，不直接预测政策。

### 3.4 基金申赎和机构配置

ETF及其底层资产可能受申赎、被动资金、基金排名和机构再平衡影响。资金流可以延续趋势，也可能在集中赎回时放大反转。

### 3.5 ETF组合降低个体噪声

宽基和大类资产ETF分散了单只股票的财务、停牌和个体事件风险，更接近共同宏观或风格因子。ETF层面的趋势可能比个股短期涨跌更适合研究中低频轮动。

### 3.6 A股动量并非天然更强

A股个股层面可能同时存在短期反转、壳价值、涨跌停效应和高换手噪声。ETF历史相对较短，当前存续ETF还存在幸存者偏差。因此不能从“市场情绪较强”直接推出“ETF动量必然有效”。

## 五、研究假设

### H0：无可交易动量

在真实A股ETF交易约束和成本下，过去相对强弱不能稳定预测未来可交易收益；任何历史改善都可能来自样本选择、参数挖掘或风险暴露。

### H1：大类资产相对动量

四袖套中相对较强的资产在中期具有一定延续性，扣除成本后可能优于固定持有或等权配置。

### H2：绝对动量的回撤作用

当相对强者自身趋势为负时转向流动性资产，可能降低最大回撤，但也可能在震荡期频繁踏空。

### H3：多周期信息

短、中、长周期可能分别反映反转、趋势和宏观持续性；有效策略应表现为相邻参数区域稳定，而不是依赖唯一窗口。

### H4：分层候选池

先在权益内部选择代表、再与其他大类资产比较，可以减少候选数量偏差，并保持收益来源可解释。

### H5：风险和交易约束

波动率控制、持仓分散与换手缓冲可能改善净风险调整收益，但任何模块都可能因降低市场暴露而牺牲目标收益。

### H6：扩展模块的独立性

地域、风格、行业、久期、商品和REITs只有在独立分支中产生稳定增量价值，才有资格进入组合。

## 六、允许的优化顺序

理论基础对应的研究顺序固定如下：

```text
四袖套与数据边界
-> 最简相对动量
-> 动量周期稳定性
-> TopN与分散
-> 绝对动量和风险控制
-> 成本、延迟与容量
-> 走步和前瞻验证
-> 独立扩展模块
```

不得在最简相对动量尚未成立时，同时加入均线、波动率、宏观估值、止损和多指标评分来追求目标收益。基础效应不成立时，应停止或重新提出新的经济假设。

## 七、唯一核心问题：如何尽可能高正确率地确认趋势形成

ETF动量策略的核心Alpha问题只有一个：

> 在第T日只使用当时已经知道的信息，尽可能早且尽可能准确地判断某个资产是否已经从随机波动进入具有持续性的趋势状态，并判断趋势未来是否仍有足够空间覆盖确认延迟和交易成本。

候选池、组合、风控、成本和实盘运维仍是策略能够落地的必要约束，但它们不是动量策略产生Alpha的核心问题。后续优化首先服务于趋势确认；不能用复杂组合或风险控制掩盖趋势识别本身无效。

### 7.1 “趋势形成”必须先被操作化定义

趋势不能靠回看图形主观判断。步骤04开始前必须冻结一个只用于评价、不进入信号的未来标签：

```text
在第T日发出趋势确认信号后，观察预注册的未来H个交易日：
1. 未来累计收益或相对收益超过交易成本与最低收益门槛；
2. 趋势期间的最大不利波动未超过预注册容忍值；
3. 收益不是只由单日跳空产生；
4. 信号在T时刻不使用上述任何未来信息。
```

只有满足预注册标签，才在事后评价中记为“趋势确认正确”。未来标签仅用于衡量预测质量，禁止泄漏到第T日的特征和交易决策中。

未来观察期`H`、最低收益门槛和最大不利波动阈值必须在步骤04看到结果前确定，并对相邻取值做稳定性检验。

### 7.2 正确率不能只看方向命中率

如果一个信号80%的时候赚1%，另外20%的时候亏10%，方向正确率很高，但期望收益仍然为负。因此“高正确率”至少同时包含：

| 指标 | 含义 | 防止的误判 |
|---|---|---|
| 趋势确认精确率 | 所有确认信号中，未来真正形成趋势的比例 | 频繁发信号制造表面命中 |
| 误报率 | 确认后很快失败或反向的比例 | 把随机突破当成趋势 |
| 召回率 | 所有真实趋势中，被策略及时捕捉的比例 | 只确认最明显、最晚的趋势 |
| 确认延迟 | 从趋势可能起点到发出信号的时间 | 为提高精确率而等到趋势接近结束 |
| 剩余趋势捕获率 | 确认后捕获收益占完整趋势收益的比例 | 信号正确但没有可交易空间 |
| 单次期望值 | 胜率、平均盈利、平均亏损和成本的综合结果 | 高胜率、小赚大亏 |
| 最大不利波动 | 确认后持有期间的最差逆向波动 | 忽略错误信号的尾部损失 |

优化目标不是单独最大化方向命中率，而是在可接受确认延迟下，提高趋势确认精确率和单次净期望值，同时控制误报造成的损失。

### 7.3 趋势确认需要判断的维度

以下维度是允许逐项验证的候选证据，不预设全部有效，也不允许第一版一次性全部加入：

1. **方向**：资产自身收益或趋势方向是否为正；
2. **相对强度**：相对其他资产或现金是否处于领先状态；
3. **持续性**：多个相邻观察窗口是否给出一致方向，而非单日脉冲；
4. **趋势质量**：上涨路径是否相对平滑，斜率是否足以覆盖噪声；
5. **波动调整**：相同涨幅是否由过高波动和尾部跳跃换来；
6. **突破有效性**：是否脱离原有震荡区间，而非区间内随机反弹；
7. **广度或共振**：趋势是否得到相关市场、底层成分或同类资产共同确认；
8. **可交易性**：趋势强度是否足以覆盖延迟、滑点、佣金和折溢价。

成交量、均线、突破、回归斜率、R方、波动率和市场广度都只是上述证据的可能度量，不是天然有效的指标。每增加一种度量，必须说明它解决哪一种误报，并做单变量验证。

### 7.4 确认速度与正确率的矛盾

趋势确认存在无法消除的权衡：

```text
确认越早 -> 剩余收益可能越多，但假突破和噪声更多
确认越晚 -> 信号可能更可靠，但趋势剩余空间更少
```

因此策略不能只比较哪个信号胜率最高，还必须比较确认后的剩余收益、持有期、换手和最大不利波动。一个晚到几乎没有剩余收益的“正确”信号没有交易价值。

### 7.5 趋势确认研究顺序

趋势识别模块按以下顺序逐项验证：

```text
M0：单一周期过去收益，作为最低复杂度基线
-> M1：相对强度与绝对方向分离
-> M2：相邻周期的一致性
-> M3：趋势质量或波动调整
-> M4：突破有效性
-> M5：广度或跨资产共振
-> M6：确认持续时间、迟滞和退出条件
```

- 每一步只增加一个确认维度，并与上一步进行共同区间比较。
- 上一步不具备可交易预测力时，不进入下一步堆叠指标。
- 参数选择首先看精确率、误报率、单次净期望和稳定性，其次才看最终年化收益。
- 任何组合指标都必须证明其增益不是来自更低仓位、更高Beta或删除困难时期。

### 7.6 趋势确认模块的最低通过条件

具体数值在步骤04预注册，但任何趋势确认方法至少必须满足：

1. 趋势确认精确率明显高于同一时期无条件趋势基准概率；
2. 扣除基础成本后的单次期望收益为正；
3. 信号强度分组与未来收益或趋势成功率大体单调；
4. 精确率提升不能以不可接受的确认延迟和趋势遗漏为代价；
5. 误报造成的平均损失和最差损失处于步骤01回撤约束可承受范围；
6. 相邻参数、不同市场阶段和走步窗口中的结果方向稳定；
7. 延迟1个交易日和2倍成本后仍保留正的预测与交易价值；
8. 结果不依赖单一ETF、单一年份或少数跳空行情。

若趋势确认本身不能通过，不再进入TopN、风控或扩展池优化。此时应停止当前动量假设，而不是用更多规则修饰净值曲线。

## 八、禁止的理论滥用

1. 不因某个参数回测最好，就事后声称它最符合投资者行为。
2. 不使用事后确认的牛熊市、美林时钟阶段或政策周期作为当时已知标签。
3. 不把高收益自动解释为信息反应不足，也可能只是高Beta、期限、流动性或拥挤风险。
4. 不把行业、风格和地域ETF视为完全独立资产，必须识别共同权益暴露。
5. 不因A股散户占比较高就预设动量一定强于其他市场。
6. 不用代理指数的理想收益宣称ETF策略可交易。
7. 不把增加指标数量当作理论完善；每个指标必须对应一个预注册机制。

## 九、基础理论的证伪条件

出现以下任一核心情形，应认为当前ETF动量假设缺乏足够支持，不得继续堆叠优化模块：

1. 最简相对动量在基础成本后不能优于预注册基准；
2. 收益方向在多数走步窗口中不稳定；
3. 只有单一窗口、单一ETF或单一市场阶段有效；
4. 延迟1个交易日或提高到2倍成本后效果消失；
5. 最大回撤和最长水下时间明显超出研究协议；
6. 收益主要来自持续更高的权益Beta，而非轮动选择；
7. 修复未来数据、幸存者偏差或成交错误后，效果不再存在。

证伪的是当前实现和假设，不是宣称所有市场、所有周期的动量永远无效。

## 十、理论与实证研究锚点
