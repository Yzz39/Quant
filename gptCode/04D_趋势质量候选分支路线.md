# 04D：趋势质量候选分支路线

## 状态

- 当前状态：M3F按用户授权进入探索性运行
- 当前版本：v0.3-m3f-exploration
- 所属步骤：步骤04内部候选分支，不代表允许进入步骤05
- 核心目标：提高“趋势已经形成且未来21日可延续”的确认正确率，而不是追逐文章中的最高历史收益

## 一、文章来源与可用假设

本路线综合六篇新文章、此前的ICU/Huber文章及既有研究协议。可检验的内容如下：

| 方向 | 文章中的做法 | 可借鉴部分 | 主要风险 |
|---|---|---|---|
| 斜率质量 | 归一化价格斜率乘R2 | 同时衡量方向、速度和路径线性度 | OLS对窗口末端异常点敏感 |
| 效率动量 | 区间收益乘效率系数 | 区分平滑趋势与来回震荡 | 更敏感、换手可能显著增加 |
| Huber回归 | 用稳健回归替代OLS | 降低单个极端价格点的影响 | 参数和拟合优度定义可能引入新自由度 |
| 对数价格 | 在log价格上计算趋势 | 消除价格水平量纲并使复利增长更接近线性 | 不能自动解决趋势末端反转 |
| 多因子融合 | 斜率、效率、乖离加权 | 只有独立因子均有增量时才可能提高稳定性 | 四资产横截面做Z-score和调权容易过拟合 |
| 换仓抑制 | 固定差值、倍率阈值、最短持有期 | 可降低震荡期反复换仓 | 固定阈值依赖得分量纲，最短持有期会延迟止损 |

文章报告的年化收益不能作为本项目证据：多篇文章改变了候选池并进行参数遍历；部分简化回测采用同日价格、未计费率和滑点；没有统一展示样本外、容量、点时ETF池和完整失败订单。候选池变化是收益差异的重要来源，不能与信号改进混为一谈。

## 二、执行顺序

### E0：先恢复可信基线

5. 用100,000元、分钟频率重跑M0和M2；（等待聚宽平台复核）

E0通过前，下面任何信号结果均不得运行或采纳。

### M3A：OLS斜率质量（不通过）

只替换长期相对强弱得分，保持四ETF池、126个交易日区间、月末信号、21日近期确认、Top1和全部执行规则不变。为覆盖完整的126个收益间隔，回归使用127个收盘价点：

```text
y_t = ln(adjusted_close_t)
beta = OLS(y_t ~ t)的斜率
score = beta * R2
```

使用log价格后不同ETF价格水平可直接比较，不再额外做0至1归一化。R2只衡量路径线性度，未来标签不进入得分。

不同来源中的标准化价格OLS、对数价格OLS、WLS、年化斜率和Huber实现对照见[`04E_斜率动量算法对照.md`](04E_斜率动量算法对照.md)。文章原版25点日频公式不会与本分支同时混用。

实际结果为年化8.54%、最大回撤21.13%、Calmar约0.404；但成熟实际确认标签39个仅成功10个，精确率25.64%，未达到55%门槛，因此不通过。完整记录见[`04F_M3A结果与M3B效率动量.md`](04F_M3A结果与M3B效率动量.md)。

### M3B：效率动量（代码已实现，等待聚宽运行）

同样只替换长期得分：

```text
r = ln(P_T / P_0)
ER = abs(r) / sum(abs(diff(ln(P_t))))
score = r * ER
```

分母为0时`ER=0`。该分数保留上涨和下跌方向，同时惩罚区间内反复震荡。

### M3C：乖离率趋势动量（不通过）

复现三因子源码的单因子定义，使用当前已有127个前复权收盘价即可覆盖完整计算：

```text
bias_t = P_t / MA90_t
取最近25个bias点
z_j = bias_j / bias_0
score = OLS(z_j ~ j)的斜率
```

源码中的`*10000`仅改变显示量纲，本项目首版省略，不影响排名。该因子不是“当前价格距离均线多远”的静态乖离率，而是“最近25个交易日相对MA90的强弱是否持续上升”。保持月频、21日近期确认和全部执行规则不变。

实际结果为年化7.70%、最大回撤31.37%、Calmar约0.245。年化和回撤通过，但Calmar低于0.4，因此不通过。日志可见部分未发现执行错误，完整记录见[`04G_M3C结果与M3D标准WLS.md`](04G_M3C结果与M3D标准WLS.md)。

### M3D：标准WLS斜率动量（未证明增量）

为与M3A做单变量对照，保持127点log价格、标准R2和月频，只把等权OLS替换为近期线性加权WLS：

```text
y_t = ln(adjusted_close_t)
w_t从1线性增加到2
beta_w = sum(w*(x-x_bar_w)*(y-y_bar_w)) / sum(w*(x-x_bar_w)^2)
R2_w = 1 - sum(w*(y-y_hat)^2) / sum(w*(y-y_bar_w)^2)
score = beta_w * R2_w
```

斜率和R2必须使用同一组权重。不得直接复制七星或五福代码中权重口径不一致的实现，也不同时改成25日窗口。

实际组合结果与M3A完全一致：累计收益61.48%、年化8.54%、最大回撤21.13%、Sharpe 0.317、Sortino 0.367。可见日志未发现执行错误，但附件停在2015年10月，缺少最终趋势标签汇总。因此M3D既未证明相对M3A的组合增量，也没有完整证据通过趋势精确率门槛。

### M3E：Huber稳健斜率（用户授权独立对照）

原路线要求M3A或M3D先证明斜率家族增量。用户于2026-07-13明确授权将M3E改为“Huber是否强于OLS”的独立对照实验。为避免事后调参，运行前冻结：127点log价格、`epsilon=1.345`、MAD残差尺度、最多50次IRLS、收敛阈值`1e-10`、无正则、最终Huber权重下的加权R2。完整对照规则见[`04I_M3E_Huber与OLS对照.md`](04I_M3E_Huber与OLS对照.md)。

首次聚宽结果为累计收益64.63%、年化8.90%、最大回撤21.13%、Sharpe 0.349、Sortino 0.408，按年化/回撤计算的Calmar约0.421。可见日志未发现实现或执行错误，一次真实流动性部分成交在次日按整手规则继续完成。但附件只有399行并停在2016年3月，缺少最终标签汇总；同引擎v0.9 OLS也未运行。因此该结果只说明组合绩效较旧M3A有小幅改善，尚不能证明Huber强于OLS。

### M3F：三因子等权排名融合（用户授权探索）

原路线要求M3A至M3E中至少两个版本各自通过步骤04完整门槛。现有证据不满足该条件；用户于2026-07-13明确要求继续M3F，因此M3F只作为探索性分支，不作为已预注册条件自然触发的确认性实验。

为避免OLS、WLS、Huber对同一斜率家族重复投票，M3F只使用三个不同家族：Huber斜率质量、效率动量、乖离率趋势。每个因子在当期共同可交易ETF中降序排名，证券代码用于确定性并列；将名次映射为中心化Borda分后等权平均：

```text
borda(i, k) = (N + 1 - 2 * rank(i, k)) / (N - 1)
fusion_score(i) = mean_k(borda(i, k))
k = Huber、效率动量、乖离率趋势
```

第一名为`+1`、末名为`-1`，融合分数大于0表示综合名次高于截面平均。继续使用21日近期确认、Top1、相同候选池和全部执行规则。不使用文章的0.3/0.3/0.4权重，不做Z-score和权重扫描。完整定义见[`04J_M3E结果与M3F等权排名融合.md`](04J_M3E结果与M3F等权排名融合.md)。

## 三、统一通过条件

每个分支必须独立满足步骤04/M2的全部门槛：

- 成熟的实际确认标签不少于36个；
- 趋势确认精确率不低于55%，且至少高于无条件成功率5个百分点；
- 实际确认信号未来21日平均净收益为正；
- Calmar不低于0.4；
- 最大回撤不高于34.96%；
- 年化收益不低于6.22%；
- 至少60%的完整自然年度为正；
- 不依赖单个ETF、单一年份或一笔极端交易；
- 不得出现负现金、无法解释的部分成交、重复订单或目标仓位偏差。

若多个分支通过，优先选择参数更少、换手更低、对最后一个观测点更不敏感的版本，而不是选择历史年化收益最高者。

## 五、暂不采用

- 每日调仓：与当前月频基线同时改变频率和信号，且文章显示效率策略换手显著更高；
- 最短持有3日：在当前月频策略中没有实际约束；
- 文章中的红利、创业板、纳指和黄金事后组合：违反当前四袖套核心池冻结规则；
- 成交量、情绪、宏观、RSRS、机器学习和止损：没有在这些文章中形成可直接复现的单一假设，继续保留在后续独立步骤。

候选池扩展仍按步骤02的独立版本规则执行；TopN、波动率控制和回撤降仓仍分别属于步骤06、步骤07，不能提前叠加到趋势因子测试。
