# 步骤 05｜选腿 + 加权 + 调仓节奏

> 信号排出名次后，怎么选、怎么配、多久换一次——这一层决定组合的**分散度和波动**。轮动最隐蔽的坑：拿一堆高相关的腿当"分散"。

## 一、这一步要干什么（目标）
把"排名"变成"实盘持仓"。
- **选几腿**：Top-N（N=2/3/4 待验），太少集中、太多摊平回归基准。
- **怎么加权**：等权 / 逆波动率 / 风险平价 —— 逆波动和风险平价能压组合波动。
- **调仓节奏**：月频 / 双周频 / 触发式（排名变动阈值才换）—— 影响换手（步骤9 严查）。
- **相关性过滤**：两腿 ρ>0.7 等于没分散，白扛波动。选腿时对高相关腿去重/降权。

## 二、闸门阈值（PASS 条件，明文）
- [ ] 组合层**波动/回撤优于单腿裸奔**（分散确实起作用）。
- [ ] 持仓腿两两相关性没失控（ρ>0.7 的腿不同时满仓持有）。
- [ ] 换手在合理带内（为步骤9 成本压测留余地，先粗估年换手倍数）。
- [ ] Top-N / 加权 / 频率三者组合下 Calmar ≥ 步骤4 毛版本。

## 三、输入 / 依赖
- 步骤4 通过的信号排名。
- 波动率窗口（如 60 日）、相关性矩阵。

## 四、执行动作
1. 实现 Top-N 选取 + 加权（先等权，再试逆波动/风险平价对比）。
2. 加相关性过滤（高相关去重）。
3. 扫调仓频率（月/双周/触发式）看换手 vs 收益权衡。

## 五、产出物
- 组合构建模块代码。
- Top-N × 加权 × 频率 的对照表（波动/回撤/Calmar/换手）。

## 六、不达标怎么办（回退）
- 分散没起作用 → 池子本身太同质（如全是强周期行业），回步骤2 扩池或调家族。
- 换手爆表 → 降频或上触发式换仓，别硬扛（步骤9 会因此毙掉）。
