# 步骤 07｜样本外 + 前向滚动（反过拟合命门·下）

> 最硬的诚实检验。样本内再漂亮都可能是背出来的答案；**样本外和前向滚动，才是真考试。**

## 一、这一步要干什么（目标）
用步骤6 定稿的稳健参数，检验它在"没见过的数据"上是否还成立。
- **IS/OOS 切分**：默认 IS=2020-2023、OOS=2024至今（可调，定后冻结）。
- **Walk-forward 前向滚动**：滚动窗口重估，模拟真实"边走边用"。
- **分市场状态子区间**：牛（2020-21）/ 熊（2022）/ 震荡（2023-24）各看一遍，别让某段独崩被平均值掩盖。

## 二、闸门阈值（PASS 条件，明文）
- [ ] **OOS Calmar ≥ IS 的 70%**（衰减在容忍带内，不是断崖）。
- [ ] Walk-forward 各滚动段无某段彻底失效。
- [ ] 每个子区间**回撤 ≤ 目标 + 3%**，无单区间独崩。
- [ ] IS/OOS 切分点在测试前就定死，事后没挪过（防偷看）。

## 三、输入 / 依赖
- 步骤6 定稿稳健参数（不许在 OOS 上再调参！）。
- 冻结的 IS/OOS 切分点。

## 四、执行动作
1. 只在 IS 上确认表现，OOS 一次性跑、不回头调参。
2. Walk-forward：滚动重估，拼接样本外净值。
3. 分子区间统计三指标。

## 五、产出物
- IS vs OOS 对照表 + 衰减比。
- Walk-forward 拼接净值曲线。
- 子区间表现表。

## 六、不达标怎么办（回退）
- OOS 断崖 → 大概率步骤6 还是过拟合了，回去缩自由度/取更保守高原。**严禁在 OOS 上调参救回来**（那就作弊了）。
- 某子区间独崩 → 记下是哪种行情失效，作为已知边界（或步骤8 防御补）。
