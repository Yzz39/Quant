# 步骤 10｜模拟盘 → 小额上线 → 衰减监控（策略会死，要管到退役）

> 回测过了不等于能赚钱。**纸面≠实盘，且再好的策略也会衰减。** 这一关把策略送上真金战场，并预先写好它的"死亡证明"标准。

## 一、这一步要干什么（目标）
三段递进，每段可退回：
1. **模拟盘前向（3-6个月）**：真实行情、模拟撮合，看实盘 vs 回测跟踪偏差。
2. **小额真金上线**：小仓位真钱，验证撮合/滑点/流动性的真实摩擦。
3. **衰减监控 + 退役线**：预先定死"什么信号出现就减仓/下线"，不靠临场情绪判断。

## 二、闸门阈值（PASS 条件，明文）
- [ ] 模拟盘 3-6 个月，实盘 vs 回测**跟踪偏差在容忍带内**（如月度收益差 < X%）。
- [ ] 小额上线成交价 vs 回测假设价偏差可接受。
- [ ] **退役线白纸黑字**（测试前定死，见下）：
  - edge 衰减：滚动 N 月超额转负持续 → 减仓。
  - 回撤破线：实盘回撤触及 15% → 强制降仓/暂停。
  - 跟踪偏差超限：实盘持续偏离回测 → 排查数据/执行。

## 三、输入 / 依赖
- 步骤9 通过的扣费达标策略。
- 模拟盘账户 / 小额实盘账户。

## 四、执行动作
1. 部署到模拟盘，每周记录实盘 vs 回测偏差。
2. 偏差达标 → 小额真金，继续记录。
3. 建立监控看板：滚动超额、当前回撤、跟踪偏差三个红线指标。

## 五、产出物
- 模拟盘跟踪偏差报告（周度）。
- 上线运行手册（含退役线、应急降仓流程）。
- 实盘监控看板。

## 六、不达标怎么办（回退）
- 跟踪偏差大 → 先查数据口径/执行时点（大概率是滑点或未来函数残留），别急着改策略。
- 实盘回撤破线 → 立即按退役线降仓，事后复盘是黑天鹅还是 edge 死了。
- edge 确认衰减 → 退役，回步骤1 重新立论（市场变了，逻辑要重估）。
