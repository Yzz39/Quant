# 步骤 09｜成本 / 换手 / 容量压测（终极目标兑现）

> **轮动策略的头号杀手是换手率。** 前面的净值都是"毛"的，这一关扣掉真实摩擦，看还剩多少。**终极目标首次完整、扣费后兑现。**

## 一、这一步要干什么（目标）
把纸面净值拉到实盘口径：
- **真实成本**：佣金万1、单笔最低 5 元、ETF 无印花税（type='fund'）、滑点。
- **换手率**：年换手多少倍？轮动越勤，摩擦越啃收益。
- **容量**：这策略装得下多少钱？迷你 ETF 大资金进出冲击成本爆炸。

## 二、闸门阈值（PASS 条件，明文·终极目标）
- [ ] **扣费后净值 CAGR ≥ 15%**。
- [ ] **扣费后最大回撤 ≤ 15%**（Calmar ≈ 1.0）。
- [ ] 成本拖累透明：毛→净的收益损耗逐项列出（佣金/滑点各占多少）。
- [ ] 年换手率在合理带内（换手换来的超额 > 它产生的成本）。
- [ ] 容量评估：目标资金规模下冲击成本可接受。

## 三、输入 / 依赖
- 步骤8 通过的完整策略（引擎+防御）。
- 实盘成本参数（用户口径：万1/最低5元/无印花税）。

## 四、执行动作
1. 开满真实 set_order_cost + set_slippage，重跑全区间。
2. 对比毛净值 vs 净净值，算成本拖累。
3. 统计年换手率、单次调仓平均腿数。
4. 按目标资金量估冲击成本（对照各腿日均成交额）。

## 五、产出物
- 毛 vs 净 净值对照曲线 + 成本拖累分解表。
- 换手率报告。
- 容量上限结论。

## 六、不达标怎么办（回退）
- 扣费后不达标 → **降换手**是第一优先（调仓频率降档、加换仓缓冲带/滞后带，别一有信号就动）。
- 换手降了收益也掉太多 → 回步骤4/5 重新权衡信号灵敏度 vs 摩擦。
- 容量不足 → 剔除迷你 ETF，只留流动性够的腿（回步骤2 池子）。
