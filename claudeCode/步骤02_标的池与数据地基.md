# 步骤 02｜标的池 + 数据地基（PIT）

> **整栋楼的承重地基。这一步不全绿，绝不许往上砌一块砖。** 数据脏，后面所有回撤/收益数字都是沙上建塔。

## 一、这一步要干什么（目标）
把"要在哪些 ETF 之间轮、用什么数据轮"这层地基夯死。
1. **候选池分层**：行业腿 / 宽基腿，每腿标上市年份。
2. **流动性 + 规模过滤**：剔除迷你 ETF（日均成交额/规模不达标）—— 轮动最怕买进冲击成本高、想换换不掉的僵尸标的。
3. **时点构池（PIT）**：`get_all_securities(types=['etf'], date=当日)` 按 `start_date<=date<=end_date` 取当时真实存在的标的，消**幸存者偏差**。
4. **价格口径**：后复权（`use_real_price=True`），除权除息缺口不被信号误判成破位。
5. **无未来函数**：盘中取价一律 `context.previous_date`；`set_option('avoid_future_data', True)`。
6. **定有效回测起点**：行业腿攒够 N 腿 + 够 MA 历史的日期（预计 2019–2020）；之前只能宽基轮动。

## 二、闸门阈值（PASS 条件，明文）
- [ ] 全候选池缺失率 **< 2%**（逐腿打印 NaN 占比）。
- [ ] 流动性过滤：入池腿近 60 日日均成交额 ≥ 阈值（待你定，如 ≥ 5000 万）。
- [ ] 后复权校验：任取一只有分红 ETF，除息日前后不出现"假破位"跳空。
- [ ] 未来函数自检：决策用价日期**严格 ≤ previous_date**。
- [ ] PIT 回放：逐调仓日打印入池腿数，**行业腿 ≥ 5** 才算行业轮动有效，否则降级并宽基。
- [ ] **有效起点定稿**：白纸黑字写下"从哪年起可做行业轮动"。

## 六、不达标怎么办（回退）
- 缺失率超标 → 剔除该腿或缩短回测区间到数据齐全段。
- 行业腿 < 5 → 不凑弱腿追高，缺口给宽基/国债，接受该区间"只做宽基轮动"。
- 发现未来函数 → 立刻停，改 `previous_date`，本步作废重跑。
