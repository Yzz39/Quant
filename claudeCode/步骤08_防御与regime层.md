# 步骤 08｜防御 / regime 层（低回撤主战场）

> 到这一步，edge 已经验实（步骤4-7）。现在装刹车。**你的核心教条在这关兑现：低回撤 > CAGR。** 防御切债券 ETF，不空仓、不切现金。

## 一、这一步要干什么（目标）
在已验证有效的轮动引擎上，叠加**回撤控制层**。可插拔（和步骤4信号同理，机制可换）：
- 大盘 regime 开关（如年线/趋势过滤）→ 防御时降进攻预算。
- 日频快平仓（均线破位止损）→ 补 regime 反应钝的滞后。
- 防御目的地：**债券 ETF 篮子**（如十年国债/红利低波），切到"会涨的防守资产"，不是现金。

## 二、闸门阈值（PASS 条件，明文）
- [ ] **最大回撤实打实降**（目标压到 ≤ 15%）。
- [ ] **年化砍幅 < 回撤降幅**（花小钱买大保险，收益不能陪着腰斩）。
- [ ] **Calmar 上升**（这层机制净正贡献才留）。
- [ ] **逐个机制量化边际贡献**：每加一个刹车，单独记"回撤降多少、收益让多少"。无贡献的机制删掉。

## 三、输入 / 依赖
- 步骤7 通过的稳健引擎（防御是加法，不是重构）。
- 防御标的池（债券/高股息 ETF）。

## 四、执行动作
1. 逐个叠加防御机制，每加一个跑一次对照（消融实验）。
2. 重点看熊窗（2018/2022）是否及时切债。
3. 记录每个机制的边际三指标。

## 五、产出物
- 消融实验表（无防御 → +regime → +日频止损，逐层回撤/收益/Calmar）。
- regime 切换时点日志。

## 六、不达标怎么办（回退）
- 回撤没降够 → 换更快的刹车（日频 vs 月频），但警惕 whipsaw（假信号频繁进出）。
- 收益砍太狠 → 防御触发太频繁，放宽阈值或用"半仓防御"而非全切。
- 某机制边际贡献≈0 → 删掉，别堆无用复杂度。
